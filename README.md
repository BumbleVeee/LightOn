# Feladat

Adott egy nxn-es terület, aminek az egyes elemei lámpákat jelképeznek.
Amikor rákattintunk egy lámpára, akkor az a lámpa és a szomszédai állapota is megváltozik:
ha le volt kapcsolva, akkor felkapcsolódik, ha fel volt kapcsolva, akkor le.
Kezdetben egy lámpa 20% valószínűséggel van felkapcsolva, a többi lekapcsolt állapotú.
Név nélkül nem lehet elkezdeni a játékot!

## Cél

A cél az összes lámpa lekapcsolása.
Amikor ez sikerült a felhasználónak, a program kiírja, hogy "Hurrá, meghosszabítottad a Föld életét!"

### Easter Egg (Alertek)

Név nélkül szeretnénk játszani: "Név nélkül nem tudsz játszani, a lámpák nem bíznak benned!"
Kezdésnél egy lámpa sincs felkapcsolva: "Ahww bocsi, de későn értél ide valaki már megmentette a Földet."
Játék véget ért, de rékattintunk egy lámpára: "Kétszer nem tudod megmenteni a Földet, kérlek utazz vissza az időben(indíts új játékot)!"
Az összes lámpát felkacsoltuk: "A globális felmelegedés oldalán állsz? Kérlek próbáld újra!"
